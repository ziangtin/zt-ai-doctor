# v0.2.0 - 未发布

## Added
- 新增 `zai-doctor detect` 环境探测命令：检测机器上实际安装了哪些 agent（PATH 可执行 + 全局配置目录 + Windows 注册表），支持 `--json` / `--verbose`，已建档时落盘 `.agents/.build/detect-report.md`。
- agent 映射/探测配置文件 `cli/market/agents.json`（单一来源）；项目可在 `.agents/agents.json` 深合并覆盖或新增 agent，无需改 TS。
- 新增 agent：**trae**（`.trae/rules/<id>.md` + `.trae/mcp.json`）、**lingma**（`.qoder/rules/<id>.md`；MCP 走 IDE 设置 UI，不自动写）。
- `sync --agent` 支持逗号多选（如 `--agent claude,cursor`）；新增 `--installed-only`（仅同步环境探测已安装的 agent，默认关）。
- `diagnose` 增加「Agent 探测（配置 / 环境）」并列段与环境症状。
- 新增转换 profile：`rule-md`（单条规则 -> 纯 markdown）、`rule-mdc`（Cursor/Trae/Lingma 共用的规则 frontmatter）。
- 新增文档 `docs/guides/AGENTS_CONFIG.md`（agents.json schema + 如何纯配置加 agent）。
- **药典多版本**：manifest 支持 `versions` 数组（同 id 多版本），资产 frontmatter 加 `version`（semver）；`treat --to <ver>` 装指定版本（**回退**：装新版后 `treat <id> --to <旧版>` 覆盖）；`diagnose` 增加版本滞后检测（显示 `1.0.0 -> 1.1.0`、已装版本已移除、内容已变但版本号未更新）；lockfile 记装时 version。旧 manifest 单 path 格式读时兼容，旧 lockfile 无 version 视为 `0.0.0`。新增 `core/semver.ts` + 文档 `docs/guides/MARKET.md`。
- **目录索引 README 自动生成**：`init`/`treat`/`remove` 后自动刷新 `.agents/rules/README.md` 与 `.agents/skills/README.md`——rules 为 `### {icon} [标题](./<id>.md)` + 2~4 个 `##` 章节列表项（封顶 4）；skills 为表格（技能/功能描述/配套规范/适用应用，配套规范取 skill frontmatter `rules` 渲染链接）；均按 `priority` 降序排序，heading emoji 取 frontmatter `icon`（缺省 rules 📋 / skills 🧩）。用 `<!-- zai:index-begin -->`/`<!-- zai:index-end -->` 标记段保护自定义前言（段外内容不覆盖）；skills README 带 `name`/`description` frontmatter。`README.md`、`*.override.md`、无 frontmatter 的 `.md` 不入索引也不被当资产。新增 `core/indexDoc.ts`。

## Changed
- renderer 由 6 个 per-agent TS 文件收敛为配置驱动工厂（`renderers/index.ts`），路径/聚合/action 全部读自 `agents.json`；转换逻辑抽到 `renderers/transforms.ts`。
- `AgentRenderer.detect` 更名为 `detectConfig`，语义明确为「项目配置探测」（区别于环境探测）。
- `cursor-mdc` transform 更名为通用 `rule-mdc`（Cursor/Trae/Lingma 共用）。
- **MCP 单文件模型**：项目级 MCP 源由 `.agents/mcp/<id>.md`（每 server 一文件）改为单文件 `.agents/mcp.json`（`{mcpServers:{id:body}}`）。`treat <mcp-id>` 合并写入、`trust` 按 id 过滤、`remove` 删条目、`sync` 渲染受信 server 到 `.mcp.json`（及 cursor/copilot/trae 的 mcp.json）。保留 treat/trust/lockfile，放弃 per-agent MCP 定向。
- **Claude rules 逐文件**：由聚合进 `CLAUDE.md` 改为 `.claude/rules/<id>.md`（`rule-md` 纯 markdown），不再生成 `CLAUDE.md` 与 `.agents/README.md`。

## Fixed
- **cline**：规则由单文件 `.clinerules` 改为 `.clinerules/<id>.md` 目录主格式（官方文档现以目录为主，单文件未再列入）。

## Removed
- Claude rules 不再生成 `CLAUDE.md`（项目根）与 `.agents/README.md`（聚合产物）。用户自有的 `CLAUDE.md` 不受影响。
- `.agents/mcp/` 目录（MCP 改存单文件 `.agents/mcp.json`）；MCP 不再支持 `override`（单文件模型）。

## Notes
- **windsurf**：单文件 `.windsurfrules` 经官方文档确认仍会读取，保留；现代格式为 `.devin/rules/*.md`（带 `trigger` frontmatter），可在 `agents.json` 覆盖。
- 全部 8 个 agent 的配置均对照官方文档核实，出处见 `docs/guides/COVERAGE_MATRIX.md`。
